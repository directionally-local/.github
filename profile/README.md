# Directionally Local

Coding agents and models on your own GPUs.

- **[dl](https://github.com/directionally-local/installer)**: start a coding agent with one command. Free GPT-6 and DeepSeek tokens every week, your own key, or `dl model up` to run an open model on an Nvidia GPU you own. [dl.new](https://dl.new)
- **[Autopilot](https://github.com/directionally-local/autopilot)**: the open-source coding agent harness (MIT).
- **[Hotcell](https://github.com/directionally-local/hotcell)**: sandboxes for AI agents on your own hardware (Apache-2.0).
- **[Serverless Objects](https://github.com/directionally-local/serverless-objects)**: Workers-compatible durable state on your own hardware (pre-alpha).
